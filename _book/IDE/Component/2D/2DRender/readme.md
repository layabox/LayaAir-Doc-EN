# 2D Rendering Components

There are currently 4 2D rendering components, namely 2D Mesh Renderer, Spine Renderer, 2D Trail Renderer, and 2D Line Renderer.

Note: Based on performance considerations. Only one rendering component is supported to be added to the same node.
