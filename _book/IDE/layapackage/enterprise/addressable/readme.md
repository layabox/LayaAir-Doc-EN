# Smart Asset Management Plugin

The Smart Asset Management Plugin is a tool for optimizing LayaAir Engine resource management. The plugin needs to be used in the IDE development environment for resource classification, editing, compilation, and other operations, and is used in the game runtime environment. It can improve resource loading efficiency and provide more flexible resource management methods.

The "Usage Instructions" document introduces the plugin's various functions, and the "Practical Operations" document introduces the plugin's usage process. Developers need to first browse the usage instructions document, then use the plugin according to the practical operations document.
