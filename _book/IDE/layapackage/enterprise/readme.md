# Enterprise Membership Plugins

After users activate enterprise accounts, in the "Package Manager", they can not only see resources purchased from the resource store but also enjoy enterprise plugins provided by LayaAir for enterprise users. These plugins are officially provided by LayaAir, extending more rich features for LayaAir-IDE and greatly improving user experience.

Current enterprise plugins include:

### [Performance Analysis Plugin](./performanceAnalysis/readme.md)

### [Smart Resource Management Plugin](./addressable/readme.md)

### [CPU Particle System](./cpuParticle/readme.md)

### [Spine Animation Baking Plugin](./spineBake/readme.md)

The above plugins are all paid membership plugins.

If developers need to purchase, they can open the plugin video introduction to view related services and purchase contact information.

Plugin video introduction: [https://www.layaair.com/LayaAirEnterprise/index.html](https://www.layaair.com/LayaAirEnterprise/index.html)
