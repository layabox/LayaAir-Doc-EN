* **Src** — Atlas resource.
* **Is Demo** — The `Src` content is only for demonstration in the IDE. It will automatically be cleared when published.
* **Auto Size** — Whether to automatically adjust size. If `Auto Size` is true, changing the `Src` will automatically adjust the node size to match the animation size.
* **Color** — Animation color.
* **AutoPlay** — Whether to play automatically.
* **Frame** — Current frame index.
* **Loop** — Whether to loop playback.
* **Time Scale** — Speed adjustment.
